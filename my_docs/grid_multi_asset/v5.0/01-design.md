## 1. 目标与非目标

### 1.1 目标

在 **仅现货多头**、**单账户单轨资金** 前提下：

1. **三重门禁（硬约束）：** **I、II、III** 与 [v4.0 `01-design.md`](../v4.0/01-design.md) **同一套窗口、基准与首轮红线口径**（见本文 §2）。参数集合仅当 **I ∧ II ∧ III** 同时满足方可标记为 **eligible / 可上线候选**。
2. **优化偏好（软偏好，在可行域内）：** 在满足门禁的前提下，优先最大化 **FULL 区间年化收益率**（默认主目标）；**卡玛比率** 可作为文档记录的次排序指标。Walk-Forward 综合分 **只做初筛或次要排序**，**不得**作为是否上线的唯一依据。
3. **交易内核：** 保留 **多标的网格**（`GRID_STEP_*`、`GRID_MAX_LAYER`、`LAYER_FRACTION`、逐标 water-filling 等与 v2/v4 同族逻辑），regime 与 `invested_ratio` 机制与 v4 对齐并可扩展离散搜索维（见 §3）。

### 1.2 非目标

| 类别 | 说明 |
|------|------|
| **独立 Beta 轨 / 双账户分账** | 不纳入 v5.0；不新增「贴近300的低换手资金轨」与网格轨拆分。贴指数仅通过 **同一持仓池内的 Universe 与分配规则** 完成。 |
| 衍生品 / 做空 / 期货对冲 | 不纳入 v5.0 |
| 与 JoinQuant 强制双轨同步 | 不强制；**SimTradeLab** 为规格与回测真源 |

## 2. 三重门禁（I / II / III）— 与 v4 对齐

以下窗口、**SimTradeLab `run_backtest.py`**、基准 **000300.SS**、初始资金（默认 **50 万**）与 **指标红线** 均与 [v4.0 `01-design.md` §2](../v4.0/01-design.md) **保持一致**，除非在 **`03-optimization-summary.md`** 中显式修订并说明相对 v4 的差异。

### 2.1 窗口

| 代号 | 区间 | 用途 |
|------|------|------|
| **FULL** | `2019-01-01` ～ 约定截止日（与 v2/v3/v4 全长横比时对齐） | **I、II** 主裁判 |
| **RECENT** | `2025-01-01` ～ `2026-03-31`（与 v1～v4 Holdout 一致） | **III** |
| **BEAR** | `2021-01-01` ～ `2022-12-31` | **监控 + 报告**；首轮可不作为 hard gate；若 FULL/RECENT 已过关仍须在总结中披露 |

### 2.2 指标与红线

沿用 v4 首轮建议表（FULL 最大回撤；FULL 相对 000300 超额与信息比；RECENT 年化、最大回撤、夏普）。**若 I+II+III 在结构下仍不可同时满足**，按 v4 既定原则在总结中记 **「当前结构下三重门禁不可行」**，并按 **先 I、再 II、再 III** 的顺序做有据放宽或收紧，**不得**仅用增加 trial 数掩盖空集。

### 2.3 录取与禁止项

- **录取：** 仅 **I ∧ II ∧ III** 全部满足 → **eligible**。在 eligible 内按 **FULL 年化收益率**（默认）择优为默认参数候选。
- **禁止：** 「仅 RECENT 好、FULL 崩」或 **II 失败** 的参数不得作为默认上线版本。

## 3. 策略结构（单轨）

### 3.1 逻辑组件

| 组件 | 职责 |
|------|------|
| **Universe 构建** | **锚定子集**（与沪深300高相关、高流动宽基 ETF，数量与名单由常量表 + 可选离散搜索界定）∪ **卫星子集**（行业/主题/红利等用于吃波动）。应用流动性、停牌等过滤。 |
| **Regime** | 沪深300 相对 MA120/MA250 → BULL / NEUTRAL / BEAR；**Regime 刷新** 可与 v4 一致（如周频更新 `invested_ratio`，与换股日解耦）。 |
| **仓位总额** | `invested_ratio` 三档；可参与离散搜索。 |
| **选股 / 轮岗** | `REBALANCE_FREQ`、`MAX_HOLD` 等在扩展 Universe 上选子集；**锚定标的优先入池**（「至少保留的锚定数量」可为离散搜索维）。 |
| **网格引擎** | 现有网格内核；**BEAR** 下允许引入与 v3 对齐的 **小维** 离散组合（如 `BEAR_UNIVERSE_MODE`、`BEAR_GRID_MODE`、层数上限等），避免维度爆炸。 |
| **执行** | 单轨资金池：所有买卖共用 **`invested_ratio` × 总权益** 预算；不新增账户或轨。

### 3.2 数据流（按交易日）

1. **日初：** 行情与基准 → 更新 **Regime**（及周频 `invested_ratio` 若当日为刷新日）。
2. **换仓日：** 在扩展 Universe 上选持仓 → **先满足锚定入池规则** → 余量分配给卫星；生成或调整目标标的集合。
3. **非换仓日：** 标的集合不变（除规则内剔除）。
4. **网格：** 按波动与层级计算步长 → 意向单 → 在单轨预算下 water-filling。
5. **BEAR 分支：** 若启用搜索到的熊市模式，**在 Universe 与标的集合确定之后** 应用 **网格层数/防御池** 等限制（避免与同日复衡逻辑顺序歧义）。

### 3.3 数据缺失与锚定

- **锚定标的** 遇长期缺失或无法成交时，须在实现与总结中约定：**是否允许临时剔锚**；若允许，须在 **`03-optimization-summary.md`** 中说明对 **II** 解释的注意事项。
- **II** 相对 **000300.SS**；锚定 ETF 存在跟踪误差，规格接受 **「尽量贴近而非复制指数」**，最终以门禁数值为准。

## 4. 优化与选参流程（两阶段）

### 4.1 阶段 A — 可行域（硬约束）

- 对候选参数跑 **FULL**，筛 **I + II**。  
- **可选算力优化：** 对阶段 A 通过者再跑 **RECENT 粗筛**（仅检查 III 中计算成本低或最易失败的个别指标），**减少无效全量回测**；**最终录取必须以完整 III 复核为准**。  
- 若阶段 A（及可选粗筛后）**空集**：在总结中记录结构结论，按 §2.2 处理红线与版本迭代，**不**建议仅靠 WF 综合分定参。

### 4.2 阶段 B — 可行域内排序（软偏好）

- 在 **完整满足 I+II+III** 的 **eligible** 集合中，**默认** 按 **FULL 年化收益率** 降序选取默认参数；可同时披露 **卡玛** 供人工复核。  
- **WF：** 保留 Optuna + Walk-Forward 作初筛或与阶段 A/B 并行，但 **不得**替代门禁录取。

### 4.3 搜索空间原则

- **网格 + `invested_ratio` + `REBALANCE_FREQ` + `MAX_HOLD` 等：** 与 v4 同族离散空间延续。  
- **新增/恢复维：** 锚定数量或「至少保留锚定数」、NEUTRAL/BEAR 下锚定 **权重/优先级** 旋钮（离散化）、v3 类熊市维 **小笛卡尔积**。具体网格与上下界在 **`02-plan.md`** 与 `optimize_params.py` 落档。

## 6. 已知风险（规格层）

1. **单轨** 下 **II** 仍受标的池、风格与跟踪误差约束；红线过紧时可行域可能为空 —— **属规格预期**。
