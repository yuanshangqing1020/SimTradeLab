# grid_multi_asset v2.0 — 规划中

## 待解决的 v1.0 问题

1. **熊市回撤过大（-48.47%）**：缺少大盘趋势过滤，持续下行时不断补仓
2. **平均持仓偏少（13.9 只，设计 50 只）**：筛选条件过严，需排查并调整

## 计划改进方向

- 加入大盘趋势判断（MA120），下行趋势时减仓或停止网格补仓
- 排查标的筛选条件，动态匹配候选池大小与 MAX_HOLD
- 在最优参数附近加密候选值，做第二轮精细调参
