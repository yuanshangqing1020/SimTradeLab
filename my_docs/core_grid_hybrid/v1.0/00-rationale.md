# 核心仓 + 网格混合策略 — 投资理念与设计直觉

> **定位**：在单标的上用「战略底仓 + 可交易网格活仓 + 现金储备」分工，兼顾长期目标收益与震荡区间的波动收益。本文档阐述**投资逻辑与参数直觉**，与工程规格（`01-design.md`、附录 A **trend_sizing**）互补。
>
> **工程对照**：规格、回测与参数默认值见 **[`../README.md`](../README.md)**；聚宽副本见 **`strategies_jq/core_grid_hybrid/`**。

---

## 1. 核心交易理念

| 维度 | 说明 |
|------|------|
| **标的** | 基本面较好、盈利相对稳定、具备一定波动率，且处于相对低估或安全边际尚可区间的标的（示例仅为历史上曾讨论的样式：如金达威、杭氧股份、兴发集团等；**实盘/回测须单独用当期标准筛选**）。 |
| **长期目标** | 该标的本轮计划：**组合层收益率达到约 +20% 后清仓**（见第 5 节「整体止盈」的计算口径）。 |
| **短期目标** | 在不大比例牺牲底仓的前提下，用网格在震荡中高抛低吸，**摊薄持仓成本、积累现金差额收益**；成本「极低甚至为负」是理想结果，**不能作为硬性承诺**。 |

**可行性结论（理念层）**：「底仓拿趋势 + 活仓吃波动」在理论与实务中都常见；是否跑赢纯持有或纯网格，取决于标的波动结构、费率、规则约束（如 T+1）与参数。建议在框架内做 **样本外、多标的、含摩擦成本** 的回测后再放大资金。

## 2. 资金与仓位规划（单标的示例）

以下以 **单只股票、计划最大投入 20 万元** 为例（举例股价 10 元/股，对应名义上最多约 2 万股等量）。

- **总资金池**：与「计划的最大风险敞口」挂钩的 20 万（含已买市值 + 预留现金）。
- **首笔建仓**（力求在相对低位）：**先买 1 万股（约 50% 资金变为头寸）**，其余 **约 50% 以现金** 形式保留，作为网格向下补仓与流动性缓冲。

**头寸切分（在已持有的 1 万股内部再分工）**：

| 名称 | 股数（示例） | 角色 |
|------|----------------|------|
| **战略死仓** | 5000 | 不因日常网格波动而减仓；仅服务于长线退出规则（与第 5 节整体止盈联动）。 |
| **网格活仓** | 5000 | 与现金一起在预设网格价位上买卖；可卖空「活仓」部分货源，直至活仓卖尽。 |

> **实施注意**：A 股通常为 **100 股整数倍**；示例里的 1000 股/笔需与最小买卖单位、单笔金额上限统一。若总资金或股价不同，请 **按比例缩放** 股数与每笔数量。

## 3. 网格参数设置

- **基准价格**：首笔买入 1 万股完成后的 **成交均价**（示例中为 10 元）。
- **网格步长**：**3%**（相对当前生效基准价上下各一档触发）。
- **每笔数量**：**1000 股**（或与其等值的金额；须满足最小单位）。
- **买卖规则（纪律性描述）**：
  - 价格较**当前网格基准** **上涨约 3%**（例：10 → 10.30）：**卖出 1000 股**（优先来自「网格活仓」对应额度，具体执行需在系统中定义扣减顺序）。
  - 价格较**当前网格基准** **下跌约 3%**（例：10 → 9.70）：**买入 1000 股**。
  - 卖出后若回落达到下一档买回条件，买回该数量；买入后若反弹达到上一档卖出条件，再卖出该数量。

**关于「可扛多久单边行情」的直觉**：在理想化、忽略加码补仓真实现金流曲线的前提下，**约 10 次按 3% 步长下移的阶梯买**，大致对应价格约 **-26%～-30%** 区域（复利阶梯，非简单 30%）；「股票侧可卖 10 次上涨网格」同理是量级上的风控直觉，**实盘需用回测按真实成交价、费率、是否补基准校验**。

### 3.1 须在系统中显式定义的「基准价刷新」规则（否则回测与实盘会对不齐）

任选其一，并在代码与文档中保持一致：

1. **固定锚定价**：全程以首笔建仓均价为唯一基准（简单，但在单边趋势中可能长期达不到对手盘）。
2. **成交滚动基准**：每次成交后，将基准更新为成交价或 VWAP（常见网格实现，需防止过于频繁微调）。
3. **分层/独立档位表**：预先列出离散的买卖价位表，成交后仅标记档位占用情况，基准可不随单笔跳动。

**建议在 README → 回测代码中锁定一种，并记录参数快照。**

## 4. 特殊行情应对（进阶）

### 4.1 单边下跌（防御）

- **触发**：自网格起始监控点起，股价**累计下跌超过约 15%**（文档原述为「买入 5 次 3% 台阶」的量级），认为「抄在半山腰」概率上升。
- **动作**：**放大补仓步长**（例如由 3% 调至 5% 或 8%），或 **降低单笔买入量**，避免备用现金过快耗尽。
- **补充**：可同时定义 **最大总回撤 / 最大补仓层数 / 现金穿仓即停** 等硬闸，避免文档未覆盖的极端行情。

### 4.2 单边上涨（进攻终止）

- **触发**：**网格活仓已无法继续按规则卖出**（活仓卖光），而价格仍在强势区。
- **动作**：**停止网格**，不追高补活仓；剩余 **战略死仓** 持有，直至触发第 5 节整体止盈。
- **意图**：避免在趋势段被「卖飞后追高」反复打脸，把尾仓利润交给趋势与最终退出规则。

## 5. 退出机制（整体止盈）

- **触发条件**：在该标的维度，**账户展示的整体收益率 ≥ +20%**（或你设定的其他阈值）。
- **止盈动作**：**一次性清仓该标的本轮全部剩余仓位**，结束本轮；后续按选股标准另找标的开启新循环。
- **重要口径（必须统一）**：「整体收益率」建议定义为：

  \[
  \text{收益率} = \frac{\text{当前市值} + \text{已兑现盈亏（含网格已实现）} - \text{累计净投入}}{\text{累计净投入}}
  \]

  若在策略中把网格盈利单独记账，须保证与「净投入」同源，否则会出现「股价没怎么涨但收益率 20%」或反之的理解偏差。

## 6. 实盘 / 回测前置约束清单（补全项）

在转入 SimTradeLab 或券商条件单前，建议逐条勾选：

- [ ] **T+1**：当日买入份额当日不可卖出；网格回测须按可用可卖数量撮合。
- [ ] **最小价差 /  tick**：3% 理论价是否落在合法价位上。
- [ ] **手续费、印花税、过户费、融资息**（若用）：是否纳入网格净利。
- [ ] **分红送转**：死仓与活仓的持仓成本与数量是否同步调整。
- [ ] **涨跌停 / 停牌**：无法成交时的排队与次日处理逻辑。
- [ ] **跳空**：越过网格价时，按跳空一价全成或部分成交的规则。
- [ ] **多标的资金占用**：若为组合级 20% 止盈，需定义是「单标的」还是「组合」。
