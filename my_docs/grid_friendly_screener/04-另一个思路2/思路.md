# 聚宽 (JoinQuant) 网格交易策略：纯做T落袋利润统计模型

## 1. 策略背景与解决的痛点

在传统的量化回测中，如果我们用“策略总资产”减去“死拿底仓不动总资产”来计算超额收益，往往会遇到一个反直觉的坑：**如果在长达多年的回测中遇到超级大牛市（如股票翻了5倍、10倍），网格策略会因为“不断逢高卖出”而提早清仓，导致错失后续几倍的涨幅。** 按照传统算法，这会产生巨大的“机会成本”，导致图表上的超额收益显示为惊人的负数（例如 -80万）。

但实际上，作为网格交易者，我们并不关心这种“虚假”的负数。我们真正想看的是：**无论大盘涨跌，我通过“低买高卖”到底从市场里实实在在地薅出了多少现金？**

本策略彻底重构了统计逻辑，采用了 **“收银台/存钱罐模式”**，完美解决了以下三大痛点：
1. **纯现金流统计**：彻底剥离股票自身的涨跌幅与机会成本，只统计成功配对的“高抛低吸”所产生的绝对现金利润。利润曲线永远呈**阶梯式向上**，永远不会为负。
2. **免疫分红送股（除权除息）**：自动盘前获取复权因子，遇到 10转10 等拆股行情时，自动等比例下调网格基准价，防止策略因价格突变而全仓买入或卖出。
3. **等额资金交易**：摒弃了不科学的“固定股数”交易法，采用每次交易固定金额（如10000元），自动向下取整换算为合规的股数。

---

## 2. 核心逻辑解析

### 2.1 存钱罐机制 (Piggy Bank)
策略内部维护了一个 `g.grid_t_profits` 字典。它的运作方式如下：
* **网格买入（向下突破）**：只买入并囤积便宜筹码，不计算任何利润。
* **网格卖出（向上突破）**：当筹码达到目标收益率触发卖出时，系统会计算：
  `单笔做T利润 = 卖出得到的总现金 - 锚定成本 - 双边手续费`
  然后将这笔钱存入存钱罐。图表上只绘制这个存钱罐的累计金额。

### 2.2 复权因子自适应 (Factor Adjustment)
聚宽在 `use_real_price = True` 模式下提供的是真实价格。如果在 10块钱 时发生 10转10，股价会突变到 5块钱。
策略在每天 `before_trading_start` 时会比对复权因子（Factor），一旦发现前复权因子发生变动，立刻将 `g.base_prices`（网格基准价）等比例缩水，确保网格体系完美过渡除权日。

## 3. 完整源代码

请将以下代码完整复制到聚宽平台的策略编辑区中：

```python
# 导入聚宽函数库
import jqdata
import math

def initialize(context):
    # ================= 1. 动态股票池设置 =================
    g.securities =[
        '002430.XSHE',   # 杭氧股份
        '002626.XSHE',   # 金达威
        '600141.XSHG',   # 兴发集团
        '000422.XSHE',   # 湖北宜化
        '513180.XSHG',   # 恒生科技ETF
        '512890.XSHG'    # 红利低波ETF
    ]
    
    set_benchmark('000300.XSHG')
    set_option('use_real_price', True)
    set_option('avoid_future_data', True)
    # 设置滑点
    set_slippage(FixedSlippage(0.02)) 
    
    # 交易手续费：印花税千分之0.5，佣金万分之3，最低5元
    set_order_cost(OrderCost(close_tax=0.0005, open_commission=0.0003, close_commission=0.0003, min_commission=5), type='stock')
    
    # ================= 2. 策略核心参数 =================
    g.initial_amount = 100000     # 单只标的初始建仓金额：10万
    g.grid_step = 0.03            # 网格步长（格子大小）：3%
    g.trade_amount = 10000        # 每次网格交易买卖金额：1万元
    
    # 初始化状态管理字典
    g.base_prices = {sec: 0.0 for sec in g.securities}       # 记录各个标的当前的网格基准价
    g.init_done = {sec: False for sec in g.securities}       # 记录是否已经完成初始建仓
    g.last_factors = {sec: None for sec in g.securities}     # 记录昨日复权因子（用于防除权除息Bug）
    
    # ================= 3. 做T存钱罐准备 =================
    # 只记录每次网格卖出时，实实在在装进口袋的现金利润
    g.grid_t_profits = {sec: 0.0 for sec in g.securities}

    # 获取股票中文名用于图表展示
    g.stock_names = {}
    for sec in g.securities:
        info = get_security_info(sec)
        g.stock_names[sec] = info.display_name if info else sec

def before_trading_start(context):
    # 【盘前处理】：防除权除息导致的网格错乱
    # 每天盘前获取最新复权因子，如果发生变化，说明发生了分红派息或送转
    for sec in g.securities:
        current_factor_df = get_price(sec, count=1, end_date=context.current_dt, fields=['factor'])
        if not current_factor_df.empty:
            current_factor = current_factor_df['factor'].values[0]
            # 如果建仓完毕且因子发生变动
            if g.init_done[sec] and g.last_factors[sec] is not None:
                if current_factor != g.last_factors[sec]:
                    ratio = g.last_factors[sec] / current_factor 
                    # 同步缩放网格基准价
                    g.base_prices[sec] *= ratio
                    log.info(f"【除权除息调整】{g.stock_names[sec]} 基准价自适应缩水至 {g.base_prices[sec]:.2f}")
            # 更新因子记录        
            g.last_factors[sec] = current_factor

def handle_data(context, data):
    # 用于收集当前时刻所有标的绘图数据的字典
    current_yields = {}

    for sec in g.securities:
        current_price = data[sec].price
        
        # 【异常处理】：如果标的停牌、未上市(NaN)或价格异常，跳过交易逻辑，并沿用上次数据保持图表连贯
        if math.isnan(current_price) or current_price <= 0 or data[sec].paused:
            plot_key = f"{g.stock_names[sec]}_纯做T现金(元)"
            current_yields[plot_key] = g.grid_t_profits[sec]
            continue
        
        # ================= 4. 初始建仓 =================
        if not g.init_done[sec]:
            shares_to_buy = int(g.initial_amount / current_price / 100) * 100
            if shares_to_buy > 0 and context.portfolio.available_cash >= shares_to_buy * current_price:
                order(sec, shares_to_buy)
                g.base_prices[sec] = current_price
                g.init_done[sec] = True
                log.info(f"【初始建仓】{g.stock_names[sec]} 买入 {shares_to_buy}股")
        
        # ================= 5. 网格交易核心 =================
        else:
            # 【向上突破】：触发卖出，收割利润落袋为安
            while current_price >= g.base_prices[sec] * (1 + g.grid_step):
                # 动态计算应卖出股数
                shares_to_sell = int(g.trade_amount / current_price / 100) * 100
                
                # 确保有足够的持仓可卖
                if shares_to_sell > 0 and context.portfolio.positions[sec].closeable_amount >= shares_to_sell:
                    order(sec, -shares_to_sell)
                    
                    # --- 绝对利润核算 ---
                    trade_value = shares_to_sell * current_price          # 卖出得到的总金额
                    cost_value = shares_to_sell * g.base_prices[sec]      # 当初买入这批筹码的理论成本
                    fee = max(5, trade_value * 0.0003) + trade_value * 0.0005 # 估算双边手续费+印花税
                    
                    # 净赚现金 = 卖出款 - 成本款 - 手续费
                    single_t_profit = trade_value - cost_value - fee
                    
                    # 将本次做T利润存入存钱罐
                    g.grid_t_profits[sec] += single_t_profit
                    log.info(f"【收割】{g.stock_names[sec]} 做T成功，落袋纯现金：{single_t_profit:.2f}元")
                    
                # 基准价上移一个网格
                g.base_prices[sec] = g.base_prices[sec] * (1 + g.grid_step)

            # 【向下突破】：触发买入，逢低吸纳廉价筹码
            while current_price <= g.base_prices[sec] * (1 - g.grid_step):
                # 动态计算应买入股数
                shares_to_buy = int(g.trade_amount / current_price / 100) * 100
                cost_needed = shares_to_buy * current_price
                
                # 确保有足够的现金可买
                if shares_to_buy > 0 and context.portfolio.available_cash >= cost_needed:
                    order(sec, shares_to_buy)
                    log.info(f"【加仓】{g.stock_names[sec]} 逢低买入 {shares_to_buy}股")
                    
                # 基准价下移一个网格
                g.base_prices[sec] = g.base_prices[sec] * (1 - g.grid_step)

        # ================= 6. 收集绘图数据 =================
        plot_key = f"{g.stock_names[sec]}_纯做T现金(元)"
        current_yields[plot_key] = g.grid_t_profits[sec]

    # ================= 7. 执行批量绘图 =================
    if current_yields:
        record(**current_yields)
```

## 4. 如何解读回测结果

运行完上述策略后，您需要在聚宽回测结果页面的下方找到 **【自定义数据】** 模块图表：

1. **图表形态**：由于我们去除了股票自身市值的涨跌，只记录“高卖低买”成功时产生的绝对差额，所以所有的曲线都会表现为 **完美的阶梯状平滑上升曲线**。
2. **单位解读**：图表的 Y 轴单位是**真实的人民币（元）**。
    * 比如当你看到“湖北宜化_纯做T现金”这条线最终停在 `185000` 时，意味着在这 8 年间，无论这只股票被腰斩还是翻了10倍，你光靠每一次赚两三百块钱的网格操作，累计在它身上“刷”出了 `18.5万元` 的净现金。
3. **策略优化思路**：
    * **斜率越陡峭的股票**：说明它的日内或波段震荡非常剧烈，非常适合网格交易（例如：恒生科技ETF，或者高波动的周期股）。
    * **线条长期平坦的股票**：说明该标的长期阴跌或者波动率过低，不仅没有做 T 空间，还占用了资金，在实盘中可以考虑将其剔除出网格股票池。
