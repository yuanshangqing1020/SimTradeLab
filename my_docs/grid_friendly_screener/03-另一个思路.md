设计一套用于筛选“网格交易”（Grid Trading）标的的评判表示体系，核心在于理解网格交易的盈利底层逻辑：**网格交易在震荡且高波动的市场中表现最好，最怕单边下跌（导致满仓套牢）和单边上涨（导致踏空）。**

因此，这套评判体系（我们可以称之为 **“网格适宜度模型” (Grid Suitability Model)**）需要围绕**波动性、震荡性（均值回归）、安全性、流动性和交易成本**五个维度来构建。

以下是一套可量化的评判表示设计方案：

---

### 一、 核心评价维度与量化指标 (The 5 Dimensions)

#### 1. 波动性指标 (Volatility) —— 决定网格的“利润丰厚度”
网格靠价格上下穿越网格线来回套利，波动越大，触发交易的频率越高。
*   **ATR振幅比 (ATR/Price)：** 真实波动幅度（Average True Range）除以当前股价。数值越大，说明日常波动越剧烈。
*   **历史年化波动率 (Historical Volatility, HV)：** 过去 $N$ 天（如60天、120天）的收益率标准差年化值。建议要求 $HV > 25\%$。
*   **表示符：$V$ (Volatility)**。$V$ 越大越好。

#### 2. 震荡性/均值回归指标 (Mean Reversion) —— 决定网格的“生命周期”
单边趋势是网格的死敌。我们需要标的在一定区间内来回拉锯，而不是一去不复返。
*   **赫斯特指数 (Hurst Exponent, $H$)：** 衡量时间序列的长期记忆性。
    *   $H < 0.5$：具备均值回归特性（适合网格）。
    *   $H = 0.5$：随机游走。
    *   $H > 0.5$：具备趋势性（不适合网格）。
*   **ADX (平均趋向指数)：** 衡量趋势强度的指标。$ADX < 25$ 通常被认为是震荡市。
*   **线性回归 $R^2$ 与斜率 (Slope)：** 对过去一段周期的价格做线性回归，斜率接近于0且 $R^2$ 极低，说明没有明显单边趋势。
*   **表示符：$M$ (Mean Reversion)**。回归性越强越好（即 $H$ 越小越好，$ADX$ 越小越好）。

#### 3. 安全性指标 (Safety / Fundamental) —— 决定网格的“防破产能力”
网格交易在下跌时会越跌越买，如果标的退市或价值毁灭，将导致永久性本金损失。
*   **资产类别权重 (Asset Type)：** 宽基ETF/行业ETF > 高股息蓝筹股 > 绩优成长股 > 题材股 > 垃圾股。
*   **基本面评分 (Fundamental Score)：** 如果必须做个股，需考察市盈率历史分位（PE Percentile < 50%为佳，避免高位接盘）、ROE稳定性、无退市风险（排除ST、连续亏损）。
*   **表示符：$S$ (Safety)**。设定及格线，低于该分数直接一票否决（如：ST股直接得分为0）。

#### 4. 流动性指标 (Liquidity) —— 决定网格的“执行滑点”
*   **日均成交额 (Average Daily Traded Value, ADTV)：** 保证能容纳你的资金进出。通常要求最近一个月日均成交额 > 1亿人民币。
*   **买卖价差比 (Bid-Ask Spread)：** 盘口价差越大，网格吃单的隐性成本越高。
*   **表示符：$L$ (Liquidity)**。流动性需满足最低阈值。

#### 5. 交易成本 (Friction / Cost) —— 决定网格的“网孔大小”
*   **印花税与佣金 (Transaction Fee)：** A股股票有印花税（目前为卖出万分之5），而ETF和可转债免印花税。这直接决定了你网格的“最小间隔”能设多小。
*   **表示符：$C$ (Cost)**。成本越低越好。

---

### 二、 综合评分模型设计 (The Mathematical Representation)

基于以上维度，我们可以设计一个**综合网格适宜度分数 (Grid Suitability Score, GSS)**。为了方便计算，我们将各项指标进行标准化（如 Min-Max 归一化至 0~1 之间）。

$$ GSS = (w_1 \times \tilde{V}) + (w_2 \times \tilde{M}) + (w_3 \times \tilde{S}) - (w_4 \times \tilde{C}) $$

**约束条件（一票否决机制）：**
*   如果 $L < \text{流动性阈值}$，则 $GSS = 0$
*   如果 $S < \text{安全性下限}$，则 $GSS = 0$
*   如果当前价格处于历史极高分位（如历史10年价格分位 > 80%），需警惕“高位接盘”，适当扣分。

**权重建议 ($w_1, w_2, w_3, w_4$)：**
*   **$w_2$ (震荡性)** 和 **$w_3$ (安全性)** 应当占最大权重（例如各占35%），因为“活下来”并“留在网格里”是策略运转的前提。
*   **$w_1$ (波动率)** 占次要权重（例如20%），决定你的年化收益。
*   **$w_4$ (成本)** 占10%，主要用于区分股票和ETF/可转债。

### 三、 具体的计算机/量化筛选逻辑 (伪代码表示)

如果你准备用 Python 配合量化接口（如 Tushare、AkShare）来跑这个筛选，可以参考以下逻辑流：

```python
def is_suitable_for_grid(stock_data):
    # 1. 一票否决过滤器 (Hard Filters)
    if stock_data.ADTV < 1_000_000_00: return False  # 日成交额 < 1亿
    if stock_data.is_st_or_delisting: return False   # ST或退市风险
    if stock_data.price_percentile_5yr > 0.70: return False # 价格处于历史高位(防止单边下跌)
    
    # 2. 震荡性计算 (Mean Reversion)
    hurst = calculate_hurst_exponent(stock_data.close_prices_1yr)
    adx = calculate_adx(stock_data, period=14)
    # 评分: 赫斯特指数小于0.5越小越好; ADX越小越好
    m_score = normalize(0.5 - hurst) + normalize(30 - adx) 
    
    # 3. 波动率计算 (Volatility)
    volatility = calculate_annual_volatility(stock_data.close_prices_1yr)
    atr_ratio = calculate_atr(stock_data) / stock_data.current_price
    v_score = normalize(volatility) + normalize(atr_ratio)
    
    # 4. 安全性与成本评判 (Safety & Cost)
    if stock_data.type == 'ETF':
        s_score = 1.0  # 宽基ETF无退市风险，安全性满分
        c_score = 1.0  # 无印花税，成本分满分
    else:
        s_score = normalize(stock_data.ROE) + normalize(1 / stock_data.PE)
        c_score = 0.5  # 股票有印花税，扣分
        
    # 5. 加权总分
    GSS = 0.4 * m_score + 0.3 * v_score + 0.2 * s_score + 0.1 * c_score
    return GSS
```

### 四、 结论与实战标的建议

根据这套表示系统运行后，你会发现**最适合网格交易的标的通常是以下几类**（按适宜度从高到低排序）：

1.  **高波动的宽基/跨市场 ETF：** 如 恒生科技ETF、科创50ETF、中概互联ETF。（特点：波动极大 $V$ 高，不死鸟属性 $S$ 满分，免印花税 $C$ 极低）。
2.  **周期性/震荡性强的行业 ETF：** 如 证券ETF、医药ETF、半导体ETF。（特点：具备强烈的周期均值回归特性 $M$ 高）。
3.  **高弹性可转债：** （特点：T+0交易，无印花税，下有保底，上有弹性）。
4.  **高股息大盘蓝筹股：** 如 银行、水电、高速公路等。（特点：波动率 $V$ 偏低，但基本面 $S$ 极好，通过长期网格可以不断降低持仓成本，当做收息底仓打底）。

**极度不适合做网格的标的（系统评分为低/零分）：**
*   **退市边缘的小微盘股**（安全性 $S$ 极低，一旦破位单边下跌，网格满仓直接血本无归）。
*   **处于主升浪、刚刚突破历史新高的动量股**（震荡性 $M$ 极低，呈现单边上涨趋势，网格会让你在山脚下就把筹码全部卖光，严重踏空）。
