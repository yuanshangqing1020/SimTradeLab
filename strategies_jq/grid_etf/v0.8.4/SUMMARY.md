## 2. 两大机制时代

### 2.1 相对 level 时代（v0.1 – v0.7）

| 特征 | 说明 |
|------|------|
| level 含义 | 相对底仓偏移：0=标准底仓，+N=多买 N 格，-N=多卖 N 格 |
| 上涨出口 | level≤-8 后再涨 → **破顶** 重建底仓 |
| 下跌困境 | level=+10 后不能再买，`ref_price` 锁死 → **网格冻结** |
| v0.7 改进 | 每次成交后 `_refresh_grid_shares()`；level≤-5 **提前破顶** |

### 2.2 绝对 level 时代（v0.8 – v0.8.4）

| 特征 | 说明 |
|------|------|
| level 含义 | **当前持有格数**；`base_level = base_value // grid_value` |
| 止盈后 | `_sync_level_after_trade()` 按持仓重算，非简单 level-=1 |
| level=0 | **清仓** → 清除状态 → **重装建仓** |
| 破顶 | **移除**；卖到底自然清仓重装 |
| 校准 | 每 bar `_calibrate_level_from_position()` 下调过高 level |
| 日志标签 | 重装 / 底仓到账 / 止盈（部分）/ 等级校准 / 清仓-碎股 |

## 4. 回测表现对比

> **重要：** `analyze_backtest_log.py` 的「做 T 利润」= 日志止盈净赚累加，**不等于聚宽策略总收益**。  
> 评估实盘候选须以 **聚宽收益概述（净值、回撤、夏普）** 为准；做 T 利润仅作网格效率参考。

### 4.1 聚宽净值对比（2015/01/05 ~ 2026/05/22，同区间 ★）

数据来源：各版聚宽收益概述截图。

| 指标 | v0.8.2（6k） | **v0.8.3（7k）** | v0.8.4（8k） | 最优 |

| **最大回撤** | **11.42%** | 15.09% | 16.63% | **v0.8.2** |
| 回撤区间 | 2015/06~07 | 2015/06~07 | 2015/06~07 | 同段 |
| 超额收益最大回撤 | 37.92% | 35.86% | **34.62%** | v0.8.4 |
| **夏普比率** | 0.137 | **0.153** | 0.137 | **v0.8.3** |

**解读：**

- **v0.8.3 是帕累托最优**：总收益、年化、夏普、索提诺均为三版最高；相对 v0.8.4 收益相同但回撤更小。
- **v0.8.2 是低回撤首选**：最大回撤仅 11.42%（比 v0.8.3 低 3.7pp），波动率/Beta 最低；代价是总收益少 ~4.3%（71% vs 75%）。
- **v0.8.4 被 v0.8.3 全面压制**：总收益与 v0.8.3 几乎相同，但最大回撤 +1.5pp、波动率 +0.009、夏普/索提诺均更差；**8k 单格无存在价值**。
- 三版最大回撤均发生在 **2015/06/12 ~ 2015/07/08**（股灾段）；v0.8.2 在该段表现最稳。

**单格扫描（聚宽真实净值，2015 同区间）：**

## 5. 关键实验结论

### 5.1 格距扫描（v0.1 – v0.3，原标的池）

| 格距 | 七年落袋 | 结论 |
|------|---------|------|
| 2% | 116,957 | 频率高、总量高，但易加满格冻结 |
| 3% | 97,497 | 原池格距综合最优 |
| 4% | 86,518 | 笔均最高，总量最低 |

→ **3% 为后续版本标准格距。**

### 5.2 标的池扫描（v0.4 – v0.6）

| 变更 | 效果 |
|------|------|
| 医药/中概 → 300/创业 | 消除 level=10 冻结，5/5 活跃 |
| 300 → 1000 | 总量 +38%（109k→148k），但引入 grid_shares 停摆 bug |

→ **1000 高潜力但需机制配合；v0.7/v0.8 分别用不同方式解决。**

### 5.3 机制扫描（v0.7 vs v0.8）

| 维度 | v0.7（相对 + 破顶） | v0.8（绝对 level） |
|------|-------------------|-------------------|
| level 一致性 | 可能脱节（卖侧停摆） | 成交后重算 + 校准 |
| 1000ETF | 2015 扩展仅 8k，停摆 | 47k，全程活跃 |
| 2015 扩展落袋 | 132k | **259k（+96%）** |

→ **绝对 level 是长跑关键。**

### 5.4 单格参数扫描（v0.8.1 → v0.8.4）

| 变更 | 区间 | 做 T 落袋 | 聚宽总收益 | 最大回撤 | 结论 |
|------|------|---------|-----------|---------|------|
| v0.8 → v0.8.1（8万/5千） | 2019 | 116,644 | — | — | 底仓加大但单格太小 |
| v0.8.1 → v0.8.2（5千→6千） | 2019 | 141,055 | 62.56% | **8.87%** | 2019 低回撤 |
| v0.8.2（6千） | **2015** | 257,117 | **71.07%** | **11.42%** | **低回撤首选** |
| v0.8.2 → v0.8.3（6千→7千） | 2015 | 285,153 | **75.35%** | 15.09% | **+4.3% 总收益换 +3.7pp 回撤** |
| v0.8.3 → v0.8.4（7千→8千） | 2015 | 343,284 | 75.26% | 16.63% | 做 T +20% 但净值无增益，**淘汰** |

→ **7k 单格是 2015 长跑的 sweet spot**；6k 适合回撤敏感；8k 边际为负。

## 7. v0.8.4 实验结论（负面）

v0.8.4 作为 **单格参数上界探测实验**，结论明确：

### 做 T 层面（日志）

1. 累计做 T 343k，笔均 273 元，均为全系列最高
2. 四标的做 T 利润均高于 v0.8.3（500 增幅 +36%）

### 净值层面（聚宽，决定性）

1. **总收益 75.26% ≈ v0.8.3 的 75.35%**，8k 单格未带来任何净值提升
2. **最大回撤 16.63%**，三版最高（vs v0.8.3 的 15.09%、v0.8.2 的 11.42%）
3. **夏普 0.137、索提诺 0.169**，均劣于 v0.8.3
4. **波动率 0.088、Beta 0.323**，均为三版最高

### 机制解释

- 更大单格 → 每笔做 T 利润更高，但单笔浮亏也更大
- 2015 股灾段（三版共同最大回撤区间）v0.8.4 受损最重
- 牛市连续止盈后末态 level 更低（创业/500 仅 2 格），底仓浮盈参与度下降
- **做 T 落袋 ≠ 策略总收益**；v0.8.4 的多做 T 被回撤和浮亏完全抵消

→ **v0.8.4 不建议实盘；单格参数搜索在 7k 处收敛，无需 v0.8.5（9k）。**

## 9. 结论

**grid_etf 历经十二版迭代：**

1. **v0.1–v0.7**：格距/标的池/机制渐进优化，v0.7 为相对 level 终点
2. **v0.8–v0.8.4**：绝对 level 重构 + 单格参数扫描（5k→6k→7k→8k）

**最终推荐（4 只池，8 万底仓）：**

| 目标 | 版本 | 单格 |
|------|------|------|
| **综合最优（默认实盘候选）** | **v0.8.3** | **7k** |
| **回撤优先** | **v0.8.2** | **6k** |
| 含 1000ETF | v0.8 | 5k |
| 不推荐 | ~~v0.8.4~~ | ~~8k~~ |

**v0.8.4 的价值在于验证了单格上界：7k 是 sweet spot，继续加大至 8k 只增加做 T 账面利润，不改善真实净值与回撤。** 后续无需再测更大单格。
