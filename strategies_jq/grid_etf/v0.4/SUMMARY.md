# grid_etf v0.4 回测总结

> 聚宽多标的 ETF 对称网格策略（V4 参数，**4% 格距 + 标的池重组**）。  
> 相对 v0.3 保持 4% 格距不变，**替换标的池**：移除医药/中概，换入 300ETF / 创业板。  
> 回测日志：`grid_etf_v0.4.txt` · 策略源码：`grid_etf_v0.4.py` · 日志分析：`analyze_backtest_log.py`

---

## 1. 四版演进概览

| 版本 | 格距 | 标的池 | 定位 | 核心结论 |
|------|------|--------|------|---------|
| **v0.1** | 2% | 纳指/黄金/500/医药/中概 | 首版基线 | 七年总落袋最高（11.7 万），但医药/中概 2021 年后永久冻结 |
| **v0.2** | 3% | 同上 | 格距加宽实验 | 总落袋降 16.6%，中概 2024 解冻，医药仍冻结 |
| **v0.3** | 4% | 同上 | 格距继续加宽 | 总落袋再降 11.3%，单次效率最高，冻结问题未根治 |
| **v0.4** | 4% | 纳指/黄金/500/**300/创业板** | **标的池优化** | 总落袋回升至 9.57 万，**5/5 全部活跃**，后期落袋四版最高 |

**演进路径：**

```
v0.1 ──→ v0.2 ──→ v0.3          v0.4
  │         │         │            │
 2%格距   3%格距   4%格距      4%格距（不变）
 同标的   同标的   同标的      换标的池 ← 方向转变
  │         │         │            │
 落袋最高  后期反超  效率最高    冻结清零 + 后期最强
```

v0.1–v0.3 是 **同一套框架下的格距参数扫描**（2% → 3% → 4%）；v0.4 **停止格距实验**，转向 v0.3 SUMMARY 建议的「标的池审视」——用更适配网格的 domestic 宽基 ETF 替换长期弱势、易冻结的标的。

## 2. 策略概要（v0.4）

| 项 | 内容 |
|----|------|
| 平台 | 聚宽 JoinQuant，分钟级 `handle_data` |
| 标的 | 5 只低相关 ETF：纳指、黄金、中证500、**300ETF、创业板** |
| 核心思路 | 每只标的独立维护网格：`ref_price` 为锚，跌 4% 加仓、涨 4% 减一格止盈；卖档用尽（level≤-8）后再涨则 **破顶** 重建底仓 |
| 底仓 | 每只初始约 5 万元（`base_value=50000`） |
| 网格单格 | 每格约 5000 元（`grid_value=5000`） |
| 手续费 | ETF 万一免五（`min_commission=0.1`） |
| 基准 | 沪深300（`000300.XSHG`） |

**v0.4 定位：** 在 v0.3（4% 格距）基线上验证「**换掉冻结标的**」能否在不改网格机制的前提下，恢复组合整体活跃度与后期落袋。这是四版中首次 **结构性（标的层）** 而非 **参数层（格距）** 的改进。

网格等级、破顶机制与 v0.1 完全相同，详见 [v0.1 SUMMARY 第 3 节](../v0.1/SUMMARY.md#3-网格等级与破顶机制详解)。

## 3. v0.4 相对 v0.3 的代码差异

两版策略文件均为 141 行，**格距与网格逻辑完全相同**，仅 `g.etf_list` 变更：

```python
# v0.3
g.etf_list = [
    '513100.XSHG',  # 纳指ETF
    '518880.XSHG',  # 黄金ETF
    '510500.XSHG',  # 中证500
    '512010.XSHG',  # 医药ETF      ← 移除
    '513050.XSHG'   # 中概互联     ← 移除
]

# v0.4
g.etf_list = [
    '513100.XSHG',  # 纳指ETF
    '518880.XSHG',  # 黄金ETF
    '510500.XSHG',  # 中证500
    '510300.XSHG',  # 300ETF       ← 新增
    '159915.XSHE'   # 创业板       ← 新增
]
```

| 变更 | 移除标的 | 移除原因（v0.1–v0.3 实证） | 新增标的 | 新增理由 |
|------|---------|--------------------------|---------|---------|
| 换入 domestic 宽基 | 医药ETF 512010 | 三版均 level=10 永久冻结 | 300ETF 510300 | 大盘核心，波动适中，与 500 互补 |
| 换入高弹性成长 | 中概互联 513050 | 三版均最终再次满格冻结 | 创业板 159915 | 高波动利于 4% 格距触发，2022 后仍活跃 |

**保留的三只标的**（纳指/500/黄金）在 v0.3 与 v0.4 回测中做 T 利润 **完全一致**——格距与逻辑未变，仅组合成员变化。

## 7. 格距扫描 vs 标的池优化：四版经验总结

### 7.1 格距扫描结论（v0.1–v0.3，v0.3 SUMMARY 已述）

| 格距 | 总落袋 | 单次效率 | 冻结 | 综合评价 |
|------|--------|---------|------|---------|
| 2% (v0.1) | 最高 | 最低 | 2/5 冻结 | 回测落袋最大化，实盘成本高 |
| 3% (v0.2) | 中等 | 中等 | 2/5 冻结 | **格距维度的综合最优** |
| 4% (v0.3) | 最低 | 最高 | 2/5 冻结 | 效率边界验证，总量不足 |

**边际收益递减：** 2%→3% 有明显结构改善；3%→4% 后期落袋几乎不变、总量再降 11%。

### 7.2 标的池优化结论（v0.4 新证）

| 维度 | v0.3（4% 同池） | v0.4（4% 换池） | 结论 |
|------|----------------|----------------|------|
| 总落袋 | 86,518 元 | 95,734 元 (+10.7%) | 换池 > 继续加宽格距 |
| 后期落袋 (2024+) | 27,959 元 | 34,955 元 (+25%) | 后期改善显著 |
| 有效网格 | 3/5 | **5/5** | 首次全活 |
| 代码改动 | — | 仅 5 行 etf_list | 极低成本的结构性收益 |

**四版一致结论：**

1. **格距不是冻结的根因，标的特性才是**——医药/中概的长周期单边下跌才是网格失效主因。
2. **换池的收益在后期释放**——前期落袋略低，但 2022 后 v0.4 持续领先。
3. **4% 格距 + 高波动标的（创业板）** 组合效果优于 4% + 低波动/单边弱势标的（医药）。
4. **300ETF 与 500ETF 有一定重叠**，组合中可考虑进一步差异化（如换红利/债券 ETF）。

## 9. 做得好的地方

1. **首次实现 5/5 全活网格**：四版中唯一末态无冻结的版本，验证换池策略有效。

## 10. v0.5 改进方向

四版实验表明：**格距扫描已到边界（v0.3），标的池优化有效（v0.4），但机制层防冻结仍未实现**。v0.5 应在 v0.4 标的基础上叠加结构性改进：

### P0 — 机制层防冻结（必须，v0.1 起未落地）

| 方案 | 说明 |
|------|------|
| **满格锚价追踪** | level=+10 后若市价继续下跌，仍允许 `ref_price` 按规则下移，使止盈线跟随市价 |
| **破底重置** | 加满格且再跌 N 格时：减仓至底仓或标记休眠 |
| **按仓位比例限仓** | 用「单标的市值 / 总资产 ≤ Y%」替代固定 10 格上限 |

> 换池是「回避」冻结，不是「解决」冻结。若 300ETF 或创业板未来进入长熊，v0.4 仍可能复现 v0.3 的困境。

### P1 — 标的池动态管理

- **定期审视**：每季度检查各标的 level、末次活跃日；level=+8 以上预警。
- **组合差异化**：300ETF 与 500ETF 相关性较高，可考虑替换其一为红利 ETF（510880）或国债 ETF（511010）以降重叠。
- **保留 v0.4 创业板**：高波动 + 4% 格距匹配度已验证，暂不换出。
- 与 `SimTradeLab/examples/grid_screener` 的日线筛标结果交叉验证。

### P2 — 参数自适应（替代全局统一格距）

- 按 ATR / 历史波动率为 **每只标的** 设 `grid_step`（高波动宽格、低波动窄格）。
- 基于四版扫描：默认 **3% 为中枢**（v0.2 格距综合最优），创业板可维持 4%、300ETF 可试 3%。

### P3 — 可观测性

- `record()` 增加各标的 `level`、冻结标志。
- 分析脚本默认日志名对齐版本号（当前 v0.4 目录内脚本注释仍为 v0.2，运行时需 `--log grid_etf_v0.4.txt`）。
- 增加冻结诊断、末次活跃日面板。

### P4 — 评估指标

- 除做 T 利润外，跟踪：**分标的总收益贡献、最大/grid 占用、冻结时长、有效网格活跃率**。
- 对比「换池前后期落袋」与「机制改进前后落袋」，分离标的效应与机制效应。

## 12. 结论

**v0.4 在 v0.3 的 4% 格距基线上替换标的池（移除医药/中概，换入 300ETF/创业板），七年总落袋 9.57 万（比 v0.3 高 10.7%），末态 5/5 全部活跃，2024–2026 后期落袋 3.50 万为四版最高。**

四版实验的完整结论是：

1. **格距扫描（v0.1–v0.3）**：宽格距单调降低总落袋、提高单次效率，v0.2（3%）为格距维度综合最优；继续加宽至 4% 边际收益递减。
2. **标的池优化（v0.4）**：换池以极小代码改动获得 **+10.7% 总落袋** 和 **5/5 全活**，后期落袋 **+25%**，效果优于继续调格距。
3. **冻结根因是标的 + 机制**：医药/中概的长熊导致加满格，换池可回避但 **满格锚价追踪等机制改进仍必须实现**。
4. **v0.5 推荐路径**：v0.4 标的池 + v0.2 的 3% 格距（或 per-标的自适应）+ P0 防冻结机制。
