## 2. 两大机制时代

### 2.1 相对 level 时代（v0.1 – v0.7）

| 特征 | 说明 |
|------|------|
| level 含义 | 相对底仓偏移：0=标准底仓，+N=多买 N 格，-N=多卖 N 格 |
| 上涨出口 | level≤-8 后再涨 → **破顶** 重建底仓 |
| 下跌困境 | level=+10 后不能再买，`ref_price` 锁死 → **网格冻结** |
| v0.7 改进 | 每次成交后 `_refresh_grid_shares()`；level≤-5 **提前破顶** |

### 2.2 绝对 level 时代（v0.8 – v0.8.3）

| 特征 | 说明 |
|------|------|
| level 含义 | **当前持有格数**；`base_level = base_value // grid_value` |
| 止盈后 | `_sync_level_after_trade()` 按持仓重算，非简单 level-=1 |
| level=0 | **清仓** → 清除状态 → **重装建仓** |
| 破顶 | **移除**；卖到底自然清仓重装 |
| 校准 | 每 bar `_calibrate_level_from_position()` 下调过高 level |
| 日志标签 | 重装 / 底仓到账 / 止盈（部分）/ 等级校准 / 清仓-碎股 |

## 5. 关键实验结论

### 5.1 格距扫描（v0.1 – v0.3，原标的池）

| 格距 | 七年落袋 | 结论 |
|------|---------|------|
| 2% | 116,957 | 频率高、总量高，但易加满格冻结 |
| 3% | 97,497 | 原池格距综合最优 |
| 4% | 86,518 | 笔均最高，总量最低 |

→ **3% 为后续版本标准格距。**

### 5.2 标的池扫描（v0.4 – v0.6）

| 变更 | 效果 |
|------|------|
| 医药/中概 → 300/创业 | 消除 level=10 冻结，5/5 活跃 |
| 300 → 1000 | 总量 +38%（109k→148k），但引入 grid_shares 停摆 bug |

→ **1000 高潜力但需机制配合；v0.7/v0.8 分别用不同方式解决。**

### 5.3 机制扫描（v0.7 vs v0.8）

| 维度 | v0.7（相对 + 破顶） | v0.8（绝对 level） |
|------|-------------------|-------------------|
| level 一致性 | 可能脱节（卖侧停摆） | 成交后重算 + 校准 |
| 1000ETF | 2015 扩展仅 8k，停摆 | 47k，全程活跃 |
| 破顶 | 33 次提前破顶 | 无；卖到底→清仓→重装 |
| 2015 扩展落袋 | 132k | **259k（+96%）** |
| 重装次数 | 5 | 29 |

→ **绝对 level 是长跑关键；破顶换重装。**

### 5.4 单格参数扫描（v0.8.1 → v0.8.2 → v0.8.3）

| 变更 | 区间 | 落袋 | 笔均 | 结论 |
|------|------|------|------|------|
| v0.8 → v0.8.1（去1000 + 8万底仓 + 5千格） | 2019 | 116,644 | 158 | 底仓加大但单格太小，**-15%** |
| v0.8.1 → v0.8.2（5千→6千） | 2019 | 141,055 | 191 | **+21%**，4 只池 2019 最优 |
| v0.8.2 → v0.8.3（6千→7千） | 2015 | 285,153 | 226 | **+11%**，全系列做 T 总量/笔均双冠 |

→ **8 万底仓 + 7 千单格** 在 2015 长跑验证通过；边际收益仍为正，但需关注牛市末态低 level 与现金闲置。

## 7. v0.8.3 优劣势

### 优势

1. **2015 扩展做 T 落袋 285k**，超越 v0.8（259k）和 v0.8.2（257k），全系列最高
2. **笔均 226 元** 为全系列最高（v0.8.2 为 203，v0.8 为 172）
3. **单格 7 千 + 8 万底仓** 经 v0.8.1→v0.8.2→v0.8.3 三轮 A/B 验证，边际收益仍为正
4. **4/4 全程活跃**，无 1000 上市/停摆复杂度
5. 四标的做 T 利润均不低于 v0.8.2 同区间（500 基本持平，其余 +15~18%）

### 代价

1. **期末持仓暴露更低**（20.4% vs v0.8.2 的 28.4%）：牛市连续止盈后创业/500 末态仅 2~4 格，底仓浮盈参与度下降
2. **组合总资产（估）略低**（794k vs v0.8.2 823k）：落袋更高但底仓+浮盈合计略逊
3. **更大单格 = 更少格数**：`base_level` 11（vs v0.8.2 的 13），加仓缓冲格数减少 2 格
4. **做 T 利润 ≠ 总收益**：需结合底仓浮盈、资金利用率综合评估
5. **缺 2019 起点对照日志**：4 只池 2019 区间是否仍优于 v0.8.2 尚待补跑

## 9. 结论

**grid_etf 历经十一版迭代，形成两条主线：**

1. **v0.1–v0.7**：格距/标的池/机制渐进优化，v0.7 为相对 level 终点（139k，5/5 活跃）
2. **v0.8–v0.8.3**：绝对 level 重构，2015 扩展落袋翻倍；单格参数从 5k→6k→7k 逐步验证

**v0.8.3 在 2015 扩展区间达到 285k 做 T 落袋、226 元笔均，为全系列做 T 指标双冠。** 若优先最大化网格落袋、接受牛市末态较低持仓暴露，推荐作为下一版实盘候选。

若需 **2019 区间 4 只池** 或 **更高期末持仓占比**，仍用 **v0.8.2**（8 万/6 千）；若需 **1000ETF**，用 **v0.8**（5 只池）；若偏好破顶机制，用 **v0.7**。

**待办：** 补跑 v0.8.3 的 2019 起点回测，与 v0.8.2 同区间公平对比。
