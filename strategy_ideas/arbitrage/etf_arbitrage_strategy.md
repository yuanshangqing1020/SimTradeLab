# ETF瞬时折溢价套利策略 (ETF Arbitrage)

## 1. 核心原理
ETF（Exchange Traded Fund）拥有两套价格体系：
1. **二级市场价格 (Price)**：在交易所买卖的实时交易价格，由市场供需决定。
2. **一级市场净值 (IOPV/NAV)**：ETF背后持仓的一篮子股票的实时总价值 (Intraday Indicative Value)。

当这两者出现偏差时，就产生了无风险套利机会。

### 1.1 折价套利 (Discount Arbitrage)
*   **现象**: `Price < IOPV` (ETF被低估)
*   **操作**:
    1.  **买入ETF**: 在二级市场低价买入 ETF 份额。
    2.  **赎回**: 在一级市场向基金公司申请赎回，换回一篮子股票。
    3.  **卖出股票**: 在二级市场将换回的股票按市价卖出。
*   **收益**: `(IOPV - Price) - 交易成本`

### 1.2 溢价套利 (Premium Arbitrage)
*   **现象**: `Price > IOPV` (ETF被高估)
*   **操作**:
    1.  **买入股票**: 在二级市场买入ETF对应的一篮子成分股。
    2.  **申购**: 在一级市场用股票换取 ETF 份额。
    3.  **卖出ETF**: 在二级市场将 ETF 按高价卖出。
*   **收益**: `(Price - IOPV) - 交易成本`

## 2. 门槛与限制 (为什么它是大资金的游戏？)
虽然逻辑简单，但实操门槛极高：

1.  **资金门槛**:
    *   ETF申赎有最小单位（最小申赎单位），通常为 **90万份 - 100万份**。
    *   以沪深300ETF (510300) 为例，单次操作门槛约 **300万 - 400万人民币**。
    *   散户资金不足无法进行申购赎回，只能做二级市场买卖。

2.  **速度要求 (T+0)**:
    *   必须使用程序化交易（如 QMT、Ptrade）的**一键篮子交易**功能。
    *   必须在毫秒级/秒级完成“买入-申赎-卖出”闭环，否则价格波动（滑点）会吃掉利润。
    *   A股T+1制度下，ETF申赎机制变相实现了T+0（当日买ETF当日可赎回，赎回的股票当日可卖）。

3.  **成本摩擦**:
    *   交易佣金 (买卖双向)。
    *   印花税 (卖出股票时收取 0.05%)。
    *   过户费。
    *   ETF申赎费（部分ETF有，部分豁免）。
    *   通常需要 **0.15% - 0.2%** 的价差才能覆盖成本并获利。

## 3. 策略实现 (QMT)

### 3.1 监控雷达 (Radar)
我们需要一个实时监控脚本，不断对比 `Price` 和 `IOPV`。

*   **数据源**: QMT `xtdata`。
*   **难点**: `IOPV` 并非所有Tick数据都直接提供。若不提供，需自行订阅指数或计算成分股总市值（计算量大）。

### 3.2 交易执行
需要调用 QMT 的算法交易接口或高级篮子交易接口。

```python
# 伪代码逻辑
if premium_rate < -0.002: # 折价 > 0.2%
    # 1. 算法单迅速买入 ETF
    algo_buy(etf_code, volume=900000)
    
    # 2. 赎回 (Purchase/Redemption)
    redeem_etf(etf_code, volume=900000)
    
    # 3. 算法单迅速卖出篮子股票
    basket_sell(stock_list)
```

## 4. 散户/小资金怎么玩？
对于无法进行申赎的小资金，可以利用此逻辑进行 **“折价定投”**：

*   **策略**: 只做折价时的买入。
*   **逻辑**: 当监测到 ETF 大幅折价（如 > 0.3%）时，买入并持有。
*   **优势**: 相当于以 99.7折 的价格买入一篮子优质股票，长期持有自带超额收益 (Alpha)。
*   **避坑**: 严禁在大幅溢价时买入（除非做短线趋势）。

## 5. 风险提示
1.  **滑点风险**: 申赎过程中市场剧烈波动。
2.  **停牌股风险**: 赎回的一篮子股票中若有停牌股，必须现金替代，可能面临额外成本（现金替代溢价）。
3.  **流动性风险**: 某些小众ETF流动性差，买不到或卖不掉。
